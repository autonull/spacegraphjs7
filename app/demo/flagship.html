What makes it more than a demo

Every affordance is a host policy over the same small library contract. No library change was needed to add a domain.

Freeform by default

Damped zero-gravity scopes settle, sleep, and warm-start. Lanes are an opt-in policy for one scope, never the global grid.

One position authority

Scope simulation owns coordinates. Physics is isolated pointer play, reconciled at rest — the two never fight over a node.

Contract, not branches

Depth and affordances are gated by renderer capabilities. Swap 2D for 3D without a backend check in host code.

Vision-gated

Overlap, legibility and layout score are measured on captured scenes, including reduced-motion and failure states.

Every rectangle is a portal

One node, four representations. Zoom chooses the rung, activity can promote it, and poor legibility demotes it. At the last rung the rectangle becomes a nested graph.

One workspace, four domains

Agent, workflow, filesystem and data stay isolated. Three inter-graph links carry one trace from a metric back to the artifact that produced it, and a two-run diff is derived from captured kernel history.

Cross-domain trace

One action walks metric → commit → pipeline step → agent artifact, moving each canvas camera without merging a single model.

History-derived diff

Two kernel snapshots produce added, removed and changed nodes. The view recomputes its diff from history, not from a written fixture.

Shareable argument

Reviewer notes ride on rendered node data, travel in the full-state link, and are bundled with the exports into one audit report.

One clone, one install, one command

The canonical fixture needs no provider credentials. It is the same input used by the study harness and the tests. 

git clone https://github.com/autonull/spacegraphjs.git
cd spacegraphjs
pnpm install
PI_LOCAL_FEED=1 pnpm --filter pi dev   # open the printed URL

pnpm --filter pi test                  # fold, selectors, scopes, study protocol
pnpm --filter pi verify:visual         # vision-gated capture matrix
pnpm --filter pi verify                # one-way dependency guard

Honest status

Immersion is exploratory, not a default. The five-task study protocol and harness are complete, but the participant run has not happened: no claim is measured yet. If the graph loses to the transcript on success and time, the result is published as-is, immersive work stops, and the library remains the deliverable. WebXR, sound and haptics are report-only seams.
