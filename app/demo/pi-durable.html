Durable sessions, mapped.

Pi Durable commits conversation state to storage. This private workspace consumer folds those commits into one kernel per tab and places them as a graph, a task tree, or an ordered timeline. No provider, API key, or flagship default changes.

Run it locally

pnpm install
pnpm --filter pi-durable dev      # http://localhost:5176
pnpm --filter pi-durable verify:fast
pnpm --filter pi-durable shots:all

Full commands, scenarios and API routes live in the app README.
